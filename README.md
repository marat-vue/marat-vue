## Коммерческая разработка

### [ПроТех76 →](https://протех76.рф/)

**Интернет-магазин спецтехники, запчастей и навесного оборудования.**

Участвовал в разработке интернет-магазина техники Rippa и комплектующих. Сайт помогает покупателю найти нужную технику, подобрать запчасти и навесное оборудование, сохранить интересующие позиции и собрать товары в корзине.

**Основные возможности сайта:**

- **Каталог с категориями и фильтрами** — навигация по ассортименту и сужение списка товаров для поиска нужной позиции.
- **Карточки товаров** — отдельные страницы для знакомства с выбранной техникой, запчастями и оборудованием.
- **Избранное** — сохранение интересующих товаров, чтобы вернуться к выбору позже.
- **Корзина** — сбор выбранных позиций в одном месте перед покупкой.

Особенность проекта — работа с разными группами товаров в одной витрине: от спецтехники до отдельных комплектующих. Структура каталога помогает начать поиск с нужного раздела, а избранное позволяет вернуться к заинтересовавшим позициям перед покупкой.

## Другой опыт

### Яндекс Крауд

**Специалист по разметке данных.**

Занимался проверкой корректности данных и оценкой ответов Алисы. Работа включала проверку информации по источникам, оценку поведения помощника и сравнение вариантов ответов.

**Основные задачи:**

- **Проверка данных и источников** — сверял сведения с источниками и оценивал корректность информации.
- **Оценка проактивности Алисы** — оценивал, насколько уместно помощник проявляет инициативу в общении с пользователем.
- **Сравнение ответов в формате SBS (side-by-side)** — сопоставлял варианты ответов, оценивая качество оформления, читаемость и подачу.

**Рейтинг грамотной разметки — 95%.**
